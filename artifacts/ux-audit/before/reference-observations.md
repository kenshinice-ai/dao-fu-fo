# Reference observation: Bible Atlas

Reference inspected: `https://bible-atlas-6h7.pages.dev/`

The useful structural observations are:

- A compact hero is followed by a short era rail, then a bounded workspace with the visual canvas and an adjacent browser/inspector. The reference does not make the user walk through repeated full-width chapters before reaching the active tool.
- Navigation and filters are concentrated into compact horizontal controls. Counts are visible in object-type controls, so a filtered browser does not imply that the dataset is small.
- The workspace keeps the visual surface and object browser in one viewport. The browser owns its own scroll region instead of adding every result to document height.
- Timeline is a separate, bounded visual section with a compact header and local controls; it does not repeat every event as a second and third full record list.
- The reference's product principle is useful as information architecture only: current mode controls the dominant surface, adjacent evidence stays nearby, and the URL carries the current state. The museum will keep its own paper, ink, serif/sans typography, tradition colors, evidence labels, and restrained editorial tone.
