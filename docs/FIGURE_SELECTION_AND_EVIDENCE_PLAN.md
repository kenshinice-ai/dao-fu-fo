# 人物选择与证据分层计划

状态：完整 Alpha 人物集合已同步到 Cloudflare production；12 位人物中 6 位属于已审核的 Public RC2 公共集合，其余人物作为 Alpha 研究内容上线并保留审核边界。最新 production 为 90 条关系、38 个来源；成玄英与吉藏已补入城市尺度空间—时间关系。

## 1. 为什么要扩展人物入口

当前 Alpha 的 12 位人物由两层组成：隋唐长安切片的玄奘、司马承祯、孔颖达、李世民、武曌、义净、成玄英、颜师古、吉藏，以及已加入 Preview 的老子、孔子、释迦牟尼。前九位支撑制度、城市、译经和注疏网络，后三位提供跨时代、知名度更高的入口，但不会被伪装成隋唐同时代人物。

扩展人物时不按知名度简单堆叠，而使用两条同时可见的轴：

- 入口性：访客是否能快速理解他/她为什么与道、儒、佛有关；
- 证据层：该人物是历史记录中的人物、传统中的圣者，还是神话/象征性人物。

这样可以扩大入口，同时不把传说叙事伪装成同一种历史事实。

## 2. 建议的人物分层

### A. 跨时代入口人物：下一批优先

这三位最适合先加入人物导航和比较入口：

1. **老子（李耳）**：道家文本传统的入口。人物归属、传记层与《道德经》作者/编纂问题必须分开；不能把“老子说”直接等同于单一历史时刻。
2. **孔子（孔丘）**：儒家经典、教育和政治伦理的入口。与《论语》建立“相关文本/传述”关系，但要保留编纂和弟子记录层。
3. **释迦牟尼佛（Śākyamuni / Gautama Buddha）**：佛教思想与僧团传统的入口。早期文本、后世传记、佛陀形象和神圣叙事分层呈现。

建议先增加这 3 位，而不是立即把神话人物全部放进同一个人物列表。这样能明显提高可识别度，同时仍能和当前三传统展览保持连贯。

### B. 跨传统与隋唐之间的桥梁：第二批

- 孟子：儒家伦理与政治思想的延伸入口；
- 庄子：道家文本、寓言和解释传统的入口；
- 菩提达摩：佛教传播与禅宗记忆的传统人物案例；
- 龙树：印度佛教思想与东亚解释史之间的跨区域桥梁；
- 张道陵：道教教团传统与后世祖师叙事的案例。

B 类人物应在 A 类完成来源和审核后再增加，避免人物数量增长快于关系、来源和双语质量。

### C. 神圣/神话宇宙：独立于历史人物列表

- 观音：以佛教神圣人物/菩萨形象处理，不标成可考历史人物；
- 太上老君：作为老子的后世神格化/神圣身份处理，不与老子实体合并；
- 伏羲、女娲、盘古等：作为神话宇宙或文明原型入口，使用 `mythic_symbolic` 证据层，不填写伪造的历史生卒年。

C 类更适合进入“神圣地理 / 神话宇宙 / 文明原型”专题，而不是当前隋唐历史人物的默认列表。相关地点也应留在 sacred cosmos 层，不能直接落到现实地图经纬度上。

## 3. 数据模型需要的最小优化

现有模型已经具备 `historical_documented`、`traditional_account`、`mythic_symbolic`、`later_deification` 等证据层，能够支撑上述分层。补人物前仍建议做两项小改动：

1. 为 figure profile 增加明确的 `figureClass`：`historical_person`、`traditional_sage`、`sacred_figure`、`mythic_persona`；
2. 将 figure 的 `historicity` 增加 `mythic`，并允许神话人物使用 `traditional_date` 或 `atemporal`，不要求虚构的历史年份。

关系层还应优先补充“传统归属/后世神格化/文本传述”类关系，避免用 `influenced` 代替证据不足的“相关”或“归属”判断。

## 4. 每位新增人物的最低内容卡

- 中英文名称、别名与原名；
- 人物类别与证据层；
- 可核验的生平/活动范围，或明确标记为传统日期/无历史年代；
- 与一部或多部文本的关系，区分“作者”“传述”“后世归属”；
- 至少一个 edition、item 或 precise 且已验证的外部来源；
- 至少一个人物—文本、人物—地点或人物—机构关系；
- 双语策展说明、研究说明和不确定性说明；
- 事实、传统、双语、权利、编辑和 schema 审核记录。

## 5. 推荐执行顺序

1. 先把老子、孔子、释迦牟尼作为“跨时代入口”加入 Alpha，但暂不放入当前 Public RC；
2. 完成 3 位当前 Public RC 人物的审核，避免新人物遮蔽发布主线；
3. 为 A 类人物建立文本、地点、传统和后世叙事关系；
4. 再决定 B 类桥梁人物是否进入下一次 Public RC；
5. 最后单独设计 C 类神话宇宙，不把神话人物混进历史人物数量指标。

## 6. 人物—空间—时间才是人物条目的最小完整单元

人物卡片不应只有姓名、简介和生卒年。进入“重点人物”层的最低条件，应是至少形成一个可追溯的三轴单元：

```text
人物
 ├─ 时间：生平/活动/文本传播/制度记忆中的哪一个阶段
 ├─ 空间：现实地点、机构、路线节点或神圣象征空间
 └─ 证据：这一组人物—时间—空间判断由什么来源支持
```

### 6.1 时间不能只有一条生卒年

对跨时代人物，至少区分：

- `life`：人物的历史生命区间；
- `activity`：可核实的活动期；
- `textual_circulation` / `translation`：文本或思想进入当前展览时空的阶段；
- `cult_emergence` / `deification`：后世信仰、神格化或制度记忆形成的阶段；
- `traditional_occurrence`：只属于传统叙事的时间，不强行换算成历史年份。

因此，老子、孔子、释迦牟尼即使生存年代早于隋唐，也可以通过“源头时间 + 隋唐接受/传播时间”进入长安展览；不能把他们伪装成隋唐同时代人物。

### 6.2 空间要分四种锚点

- **生平/活动地点**：人物实际活动或有来源支撑的城市、寺院、宫观；
- **机构地点**：译场、书院、寺院、道观、官学等制度节点；
- **传播/记忆地点**：文本、注疏、祭祀、译经或后世传统形成的地点；
- **神圣/象征地点**：只进入 sacred cosmos，不进入现实经纬度地图。

地图上的点应由关系和时间共同生成，而不是在人物卡片里手填一个“核心地点”。同一人物可以有多个阶段、多个地点，但每个点都必须说明是“活动”“传播”“记忆”还是“象征”。当前 Preview 已把鹿野苑加入真实地图，并将三位跨时代人物的唐代制度/记忆接受阶段加入时间轴；完整关系派生仍是下一阶段。

### 6.3 当前 12 位人物的立体档案进度

- 12 位人物都有至少一条时间断言；
- 玄奘、司马承祯、孔颖达、老子、孔子、释迦牟尼六个 dossier 已通过“时间—空间—事件—文本—后世接受”结构门禁；
- 老子明确标为 `traditional_sage / contested`，孔子和释迦牟尼分别保留历史人物/传统叙事的证据说明；《道德经》《论语》、早期佛教经文与后世文本归属不合并处理；
- 其余六位仍是 Alpha 支撑人物；本轮已为成玄英、吉藏补入有来源边界的长安空间—时间关系，李世民、武曌、义净、颜师古上一轮已补入事件/空间关系。下一步应继续补齐这些关系的正式 review checks 与言论/后世接受证据，避免人物索引只增长数量而不增长语境密度。

这说明下一步不应只增加人物数量，而应先给现有条目补齐关系闭环和来源定位。下一层的“立体完整”标准是人物、事件、地点/机构、文本/言论、历史性、后世接受都能回到同一条有时间和证据的关系网络。

### 6.4 建议的产品入口

Explore 以后应支持三种互相联动的入口：

1. **人物先行**：选择人物后显示其时间阶段、空间节点和相关文本；
2. **空间先行**：选择长安、洛阳、敦煌或机构后显示在此活动/传播/被记忆的人物；
3. **时间先行**：拖动历史区间后只保留在该阶段有明确活动、传播或记忆关系的人物。

三种入口最后都落到同一个关系集合，而不是三套互相矛盾的静态名单。当前地图缩放、拖动和节点点击是交互基础；下一层应是“节点—时间阶段—人物详情”的联动。
