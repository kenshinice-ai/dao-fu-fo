## 2. 已确认并继续生效的四个决策

### A. 下一批内容路线

请选择一个主路线。候选人物只是候选池，尚未进入 authoring，也不代表项目已经认定其具体地点或关系。

#### A1（建议）：先做“可审计的人物—地点—事件网络”

先扩充具有明确历史/文献入口、能够形成地图网络的人物，再把神话/神圣层作为独立轨道接入：

- 先秦思想：庄子、孟子；
- 道家/道教源流：张道陵、葛洪；
- 佛教源流与入华：阿育王、龙树、鸠摩罗什、法显；
- 后续可接入：智顗、慧能、菩提达摩、朱熹等跨时期桥梁。

建议第一批只选 6–8 人，保证每个人都能完成“人物—时间—地点/待核位置—事件/文本—关系—来源”的闭环。

#### A2：先做“神话与神圣空间”

先建立盘古、女娲、伏羲、黄帝、西王母、太上老君等传统/神圣入口，但只进入传统顺序、文献见证和 symbolic cosmos；现实地图只收录有证据的后世祭祀、图像、遗址或记忆地点。

这条路线能最快体现“神话时代”，但需要先确认神圣画布和身份节点的展示方式，不能直接把神话人物放入历史地图。

#### A3：人物广度优先

一次加入 12–20 位著名人物，快速扩大搜索和传统入口，再逐步补地图与关系。

这条路线视觉数量增长最快，但会暂时产生较多 `position_pending` 和稀疏关系，不建议作为下一轮的默认执行方式。

### B. 人物身份是否严格分层

建议确认以下规则：

1. `historical_person`、`traditional_sage`、`sacred_figure`、`mythic_figure`、`compound_figure` 使用不同身份层；
2. 历史人物与后世神格化身份建立独立节点，通过 `deified_as`、`identified_with`、`remembered_in` 等关系连接；
3. 不把后世传说写回历史人物的生平时间和活动地点；
4. 对老子/太上老君、释迦牟尼/佛陀叙事层、张道陵/天师谱系等，默认采用分层而不是合并。

已确认并执行：严格分层、关系连接、不合并为默认规则。

### C. 地点与坐标精度

建议确认以下发布规则：

| 类型 | 现实地图 | 允许的表达 |
|---|---:|---|
| `exact_site` | 是 | 有精确遗址/建筑来源才给点；坐标必须有来源或明确坐标依据 |
| `city_centroid` | 是 | 只支持城市尺度时显示城市中心点，并明确不是具体活动地址 |
| `approximate_region` | 是，特殊样式 | 用地区/走廊表达，不伪装成精确地点 |
| `traditional_association` | 是，特殊样式 | 明确是传统关联，不写成历史事实 |
| `memory_or_cult_site` | 是 | 表示后世祭祀、艺术、遗址或文化记忆，不反推本人到访 |
| `route_corridor` | 是，线/走廊 | 表达传播、求法、游学或朝圣路线，不画伪精确逐日轨迹 |
| `symbolic_cosmos` | 否 | 只进入神圣地理画布，不写入经纬度地图 |
| `position_pending` | 否 | 保留人物入口和研究说明，不造点 |

已确认并执行：以上空间类型与坐标边界作为今后所有人物和地点的硬边界。

### D. 时间的三轨表达

建议确认每个对象可以同时拥有三种时间，但不互相覆盖：

- `historicalTime`：生平、活动、任职、旅行和可考事件；
- `traditionalTime`：谱系、神话顺序、宗教叙事和传统纪年；
- `receptionTime`：注疏、制度记忆、祭祀、神格化、艺术、朝圣和现代传播。

规则建议：

- 神话人物不强行获得伪 BCE/CE 生年；
- 传统日期必须标注 `traditional` 或 `contested`；
- 后世接受不能投影回人物的历史活动时间；
- 历史时间继续使用 BCE/CE 连续轴，并跳过 year 0。

已确认并执行：三轨并列，历史轴不吸收传统/接受史；不使用 year 0。

## 3. 每位新增人物的最低闭环

通过审核后，新增人物不得只增加一张人物卡，至少需要：

1. 身份类别与历史性说明；
2. 至少一条可审计的时间断言，或明确 `undated` / 传统时间；
3. 一个现实地点、路线、symbolic position 或明确 `position_pending`；
4. 至少一个事件、文本、制度、言论或后世影响关系；
5. 中英文标题、摘要、研究说明和来源；
6. 关系中的 `spatialRole`、`historicity`、`confidence`、`evidenceLayer` 和 `sourceIds`；
7. 若涉及神话、神格化或后世接受，必须建立独立层或明确关系限定，不并入历史生平。
